# 🎬 Movie Genre Classification

## 📌 Objective
The goal of this project is to build a machine learning model that can predict the genre of a movie based on its plot description.

---

## 🧠 Approach
- Data preprocessing and cleaning
- Text feature extraction using **TF-IDF**
- Model training using **Naive Bayes**
- Model evaluation using accuracy score

---

## ⚙️ Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorizer

---

## 📊 Model Performance
- Accuracy: ~85% (may vary based on dataset)

---

## 🚀 How It Works
1. Load dataset (`train_data.txt`)
2. Clean and format data
3. Convert text data into numerical features using TF-IDF
4. Train a machine learning model
5. Predict genre for new movie plots

---

## 🧪 Example

**Input:**
A young boy discovers magical powers and saves the world

**Output:**
Fantasy / Adventure

---

## 📁 Project Files
- `movie_genre_classification.ipynb` → Main notebook
- `train_data.txt` → Dataset

---

## 📌 Conclusion
This project demonstrates how Natural Language Processing (NLP) techniques can be used to classify text data effectively and build predictive models.
