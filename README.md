# Spam SMS Detection

## Objective
Detect whether an SMS is Spam or Not Spam using Machine Learning.

## Technologies
- Python
- Pandas
- Scikit-learn

## Model
- TF-IDF
- Logistic Regression

## Accuracy
~96%

## Example
Input: "Free entry in a contest! win cash now"  
Output: Spam
